# cta

Custom **custom** block. Purpose: Standalone call-to-action button group using the site CTA styles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one or more CTA paragraphs (strong link primary, em link secondary, strong+em link tertiary).
