# product-table

Custom **table** block. Purpose: Tariff comparison table with label column, tariff columns, coloured header and group sub-headings.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per table row: label cell then tariff cells (text or :check:/:close: icon paragraphs); a single-cell H3 row starts a group.
