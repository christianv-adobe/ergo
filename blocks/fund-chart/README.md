# fund-chart

Custom **custom** block. Purpose: Fund allocation chart: tab bar of breakdown views (sectors, regions, largest holdings), each with a chart graphic (e.g. world map with bubbles) and a legend of series with percentages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional 1-cell intro rows; then one row per view: tab label | graphic (picture, or a table/text) | legend list (one item per series, e.g. '66,4 % Nordamerika').
