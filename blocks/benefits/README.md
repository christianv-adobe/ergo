# benefits

Custom **cards** block. Purpose: Framed or boxed list of benefit items with optional flag label.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional flag paragraph before the first item; per item: optional :icon: paragraph, H3 title, text or list.
