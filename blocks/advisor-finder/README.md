# advisor-finder

Custom **custom** block. Purpose: Advisor search results page: title, filter and sort controls, result count, list of advisors (photo, rating, name, address, distance, homepage link, badge) beside a map panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 cell heading = title; label | list = filter or sort select (bold item selected); 1 cell text = result summary; picture | details | optional badge = one advisor (details: rating, name, address, distance, links); 'Map' (or 'Karte') | content = map panel (consent notice and button); rows after the last advisor also go to the map panel.
