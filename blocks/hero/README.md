# hero

Custom **hero** block. Purpose: Page lead band with image, H1, serif title line, teaser text, price and CTAs (product pages and the landing page).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image; optional stoerer badge image; H1; title line paragraph; teaser paragraphs; optional price paragraph (bold amount); CTA paragraphs (strong link primary, em link secondary, optional :icon: token).
