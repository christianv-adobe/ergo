# carousel-reviews

Custom **carousel** block. Purpose: Slider of customer review cards (avatar, reviewer name, date, source logo, star rating, review text) with the reviewed agent and a homepage link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per review; cell 1: avatar image (or one-letter text), reviewer name (bold or heading), date line (e.g. am 16.11.2026 auf), optional source logo image, rating paragraph (5, 4,5/5 or ★★★★★), review text; cell 2 (optional): agent name, location line, optional badge image, homepage link.

## Supported variations

No variations.
