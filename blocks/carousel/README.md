# carousel

Custom **carousel** block. Purpose: Grid or slider of tiles, promo cards, article teasers or download cards.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one slide per heading (tiles: optional :icon:, heading, text, CTA; optional colour word in cell 2); with cards: one row per card with optional image, flag, heading, text, CTAs.
