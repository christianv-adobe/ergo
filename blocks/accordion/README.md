# accordion

Custom **accordion** block. Purpose: Expandable FAQ / detail items with chevron toggle.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 item title (H3); cell 2 panel content (an empty panel adopts the next block in the section, e.g. a product-table).

## Supported variations

| Variation | Option class |
| --- | --- |
| First item open | `open-first` |
| Check-icon list | `check-list` |
