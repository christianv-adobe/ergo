# tabs-content

Custom **tabs** block. Purpose: Tab bar switching between rich content panels (product options, life stages).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab; cell 1: tab label (optionally an :icon: or image before the text); cell 2: panel content (headings, text, lists) or a single link to a fragment (e.g. /fragments/tabs/einmalanlage) when the panel holds other blocks; further cells become side-by-side panel columns.
