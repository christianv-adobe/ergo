# promo

Custom **columns** block. Purpose: Promo card with optional image, flag, headline, title line, text, price and CTAs; several cards lay out in two columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: per card: optional image (+ optional stoerer image), optional flag paragraph, headline heading, optional title-line heading, text, optional price, CTA paragraphs.
