# cards-tariff

Custom **cards** block. Purpose: Tariff/plan comparison cards with optional flag badge, tagline, plan name, feature checklist, price, compare link and calculate button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tariff card; optional first cell with a short flag text (e.g. Bestseller); body cell: tagline paragraph, plan-name heading, feature list, price paragraph (e.g. z.B. 1,85 € mtl.), optional compare link paragraph, calculate button link last.
